## Concepto

Una colección se elige por las operaciones y garantías necesarias. `List` conserva secuencia y admite duplicados. `Set` representa elementos únicos según su regla de igualdad. `Queue` organiza procesamiento; `Deque` permite trabajar por ambos extremos. `Map` asocia claves con valores y no extiende `Collection`.

`ArrayList` permite acceso por índice en O(1) y agregado al final en O(1) amortizado; insertar en el medio suele desplazar elementos. `HashMap` ofrece búsqueda esperada O(1) con hashes adecuados, sin garantizar orden de iteración. `LinkedHashMap` puede conservar orden de inserción. `TreeMap` mantiene claves ordenadas con operaciones O(log n). Estas complejidades describen crecimiento, no tiempos exactos.

La colección no hace automáticamente inmutables sus elementos. `List.of` crea una lista no modificable y rechaza `null`; `Arrays.asList` tiene tamaño fijo y comparte el array de respaldo. `Collections.unmodifiableList` es una vista: cambios hechos sobre la lista original pueden verse desde ella. Elegí copias cuando necesitás aislar estructuras.

## Ejemplo

Java 21 ejecutable como `Colecciones.java`:

```java
import java.util.*;
class Colecciones {
    public static void main(String[] args) {
        List<String> lineas = new ArrayList<>(List.of("A", "A", "B"));
        Set<String> productos = new LinkedHashSet<>(lineas);
        Map<String, Integer> cantidades = new HashMap<>();
        for (String sku : lineas) {
            cantidades.merge(sku, 1, Integer::sum);
        }
        Deque<String> pendientes = new ArrayDeque<>(productos);
        while (!pendientes.isEmpty()) {
            String sku = pendientes.removeFirst();
            System.out.println(sku + ": " + cantidades.get(sku));
        }
    }
}
```

Aquí hay tres preguntas distintas: líneas originales, productos únicos y cantidad por producto. No conviene forzar todas sobre una sola lista.

## En entrevista

**Respuesta breve:** uso List para secuencias, Set para unicidad, Map para búsquedas por clave y Queue para tareas pendientes.

**Respuesta ampliada:** además considero orden, mutabilidad, tamaño, acceso concurrente y costo de operaciones. `LinkedList` no acelera búsquedas por índice; llegar al nodo puede ser O(n), aunque enlazar un nodo conocido sea barato.

## Error frecuente

Depender del orden observado accidentalmente en un `HashMap` o modificar estructuralmente una lista dentro de un `for-each` sobre ella.

## Práctica

Quitá productos repetidos manteniendo el orden en que aparecieron. Después devolvé una lista independiente no modificable.

### Pista

Combiná una estructura que conserve inserción con una copia de salida.

### Solución

`List.copyOf(new LinkedHashSet<>(lineas))` produce la secuencia buscada si no hay `null`. La copia es superficial: objetos mutables compartidos todavía pueden cambiar internamente.

## Profundización

Una colección concurrente protege operaciones documentadas, no transacciones arbitrarias de negocio. «Consultar stock y luego restar» puede necesitar una operación atómica aun usando un mapa concurrente.
