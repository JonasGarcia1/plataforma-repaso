## Concepto

Un stream describe una canalización de procesamiento sobre una fuente. No es una colección y no almacena necesariamente todos los resultados. Las operaciones intermedias, como `filter` y `map`, producen otro stream; una terminal como `count`, `collect` o `toList` solicita el resultado. Un stream consumido no se reutiliza.

`map` transforma cada elemento; `flatMap` transforma y aplana secuencias, útil para obtener todas las líneas de varios pedidos. `filter` selecciona elementos; `reduce` combina valores mediante una operación asociativa y una identidad adecuada. Los collectors expresan agrupación, partición y acumulación sin escribir manualmente cada paso.

La evaluación suele ser perezosa: no confundas describir un filtro con ejecutar una consulta. Algunas operaciones pueden optimizarse o cortocircuitarse; `peek` no es un lugar confiable para lógica de negocio. Mantené el cálculo libre de modificaciones a estructuras compartidas.

## Ejemplo

Java 21 ejecutable como `ResumenPedidos.java`:

```java
import java.util.*;
import java.util.stream.Collectors;
class ResumenPedidos {
    record Linea(String sku, int unidades) {}
    public static void main(String[] args) {
        List<Linea> lineas = List.of(
            new Linea("A", 2), new Linea("B", 1), new Linea("A", 3));
        Map<String, Integer> totalPorSku = lineas.stream()
            .filter(linea -> linea.unidades() > 0)
            .collect(Collectors.groupingBy(Linea::sku,
                Collectors.summingInt(Linea::unidades)));
        List<String> productos = totalPorSku.keySet().stream()
            .sorted().toList();
        System.out.println(totalPorSku); // A=5, B=1; orden no garantizado
        System.out.println(productos);   // [A, B]
    }
}
```

En Java 21, `Stream.toList()` devuelve una lista no modificable. Si necesitás una `ArrayList`, usá `Collectors.toCollection(ArrayList::new)`.

## En entrevista

**Respuesta breve:** separo fuente, transformaciones y resultado; uso collectors para agregaciones y evito efectos compartidos.

**Respuesta ampliada:** no reemplazo cualquier bucle por un stream. Una secuencia compleja de validaciones con salida temprana puede ser más clara de forma imperativa. Antes de usar `parallelStream`, compruebo tamaño, costo, seguridad y recursos utilizados.

## Error frecuente

Hacer `parallelStream().forEach(listaCompartida::add)` sobre una `ArrayList`. La lista no soporta esas escrituras concurrentes y el resultado puede ser incorrecto. Tampoco `Collectors.toMap` resuelve claves repetidas sin una política explícita.

## Práctica

Obtené la cantidad total de unidades positivas y los SKU distintos ordenados de la entrada del ejemplo.

### Pista

Una operación usa un stream numérico; la otra necesita unicidad y orden.

### Solución

`lineas.stream().filter(l -> l.unidades() > 0).mapToInt(Linea::unidades).sum()` devuelve 6. `lineas.stream().map(Linea::sku).distinct().sorted().toList()` devuelve `[A, B]`. Creá un stream nuevo para cada terminal.

## Profundización

`sorted` necesita considerar la entrada completa; `limit` puede cortar procesamiento, pero su ubicación cambia semántica y costo. `limit(5).sorted()` ordena cinco elementos iniciales; `sorted().limit(5)` obtiene los cinco menores del conjunto.
