## Concepto

Estos patrones cambian cómo se conectan objetos o cómo varía un comportamiento. Son breves de explicar si se parte de su intención.

- **Adapter:** traduce una interfaz ajena a la propia.
- **Facade:** ofrece una entrada simple a varios pasos.
- **Proxy:** controla acceso al mismo contrato.
- **Decorator:** agrega comportamiento envolviendo el mismo contrato.
- **Strategy:** intercambia un algoritmo.
- **Observer:** avisa a suscriptores sobre un cambio.

Varios delegan llamadas, pero no resuelven el mismo problema. Una fachada no crea transacciones y un Observer local no equivale a Kafka.

## Ejemplo

Java 21, cada tipo es deliberadamente pequeño.

```java
interface Avisos { void enviar(String texto); }
class ServicioViejo { void send(String texto) {} }

record Adaptador(ServicioViejo viejo) implements Avisos {
    public void enviar(String texto) { viejo.send(texto); }
}
record ConAuditoria(Avisos destino) implements Avisos {
    public void enviar(String texto) { destino.enviar(texto); System.out.println(texto); }
}
interface Tarifa { int calcular(int unidades); }
record Envio(Tarifa tarifa) { int cotizar(int n) { return tarifa.calcular(n); } }
```

El adaptador permite usar una API antigua; el decorator suma auditoría; `Tarifa` expresa Strategy. Un Proxy podría validar permiso antes de delegar; una Facade podría coordinar guardar y avisar.

## En entrevista

**Respuesta breve:** Adapter cambia interfaz, Decorator añade responsabilidad, Proxy controla acceso y Strategy cambia un algoritmo.

**Respuesta ampliada:** aclararía la intención antes del nombre. Por ejemplo, distintas tarifas justifican Strategy; un proveedor legado justifica Adapter. Elegiría el patrón solo si evita condicionales repetidos o acoplamiento visible.

## Error frecuente

Decir que Observer garantiza entrega durable o que los oyentes corren en paralelo. Un Observer local puede ser síncrono, fallar a mitad del recorrido y requerir reglas adicionales.

## Práctica

Componé un aviso legado con auditoría y una tarifa de 100 centavos por unidad. ¿Dónde validarías permiso?

### Pista

Los wrappers reciben y exponen el mismo contrato.

### Solución

`new ConAuditoria(new Adaptador(new ServicioViejo()))` agrega registro; `new Envio(n -> n * 100)` usa Strategy. Un Proxy exterior puede rechazar antes de delegar, con permiso tomado del contexto autenticado, nunca de un booleano enviado por el cliente.

## Profundización

Si hay reintentos, transacciones o asincronía, definí duplicados y fallos explícitamente. La estructura de un patrón no aporta esas garantías por sí sola.
