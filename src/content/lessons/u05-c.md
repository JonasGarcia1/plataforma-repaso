## Concepto

`Path` representa una ruta; no demuestra que el archivo exista. `Files` ofrece operaciones de lectura, escritura y metadatos. Decidí encoding, tamaño esperado y comportamiento ante fallos antes de elegir una función. UTF-8 explícito ayuda a mantener el mismo resultado en distintos entornos.

`Files.readString` es cómodo para archivos pequeños porque carga el contenido completo. Para un catálogo grande, un `BufferedReader` o `Files.lines` permite procesar progresivamente y limitar memoria. Contar líneas con streaming sigue tomando O(n) tiempo, pero no requiere conservar todo el texto.

Una ruta enviada por el usuario no debería permitir salir del directorio acordado. Resolver y normalizar detecta escapes léxicos como `../`; los enlaces simbólicos requieren comprobaciones adicionales y permisos del sistema. En sistemas sensibles, la validación y el uso deben considerar cambios concurrentes del archivo.

## Ejemplo

Java 21, clase completa compilable; el método necesita un archivo UTF-8 existente:

```java
import java.io.IOException;
import java.nio.charset.StandardCharsets;
import java.nio.file.*;
class CatalogoArchivo {
    static long contarProductos(Path archivo) throws IOException {
        try (var lineas = Files.lines(archivo, StandardCharsets.UTF_8)) {
            return lineas.filter(linea -> !linea.isBlank()).count();
        }
    }
    static Path resolver(Path base, String nombre) {
        Path raiz = base.toAbsolutePath().normalize();
        Path destino = raiz.resolve(nombre).normalize();
        if (!destino.startsWith(raiz)) {
            throw new IllegalArgumentException("Ruta fuera del catálogo");
        }
        return destino;
    }
}
```

La validación es deliberadamente léxica: no la presentes como protección completa frente a symlinks o carreras del sistema de archivos.

## En entrevista

**Pregunta:** ¿Cómo leerías un archivo grande sin cargarlo entero en memoria?

**Breve:** uso Path y Files, encoding explícito y lectura progresiva cuando el tamaño lo requiere.

**Ampliada:** elijo una política para entradas inválidas: rechazar todo el archivo, informar filas problemáticas o procesar parcialmente. Es una decisión del negocio que debe acompañar al código; ignorar líneas silenciosamente puede corromper una importación.
## Error frecuente

Comprobar `Files.exists` y asumir que la próxima lectura no fallará. El archivo puede desaparecer, cambiar permisos o quedar inaccesible entre ambas operaciones. Hay que manejar el error de la operación efectiva.

## Práctica

Necesitás reemplazar un catálogo pequeño sin dejar un archivo a medio escribir. Proponé una secuencia.

### Pista

Separá escritura completa de publicación del resultado.

### Solución

Escribí un temporal en el mismo sistema de archivos, cerralo y movelo al destino. Solicitá `ATOMIC_MOVE` donde esté soportado; manejá explícitamente su ausencia. No prometas atomicidad si usás una alternativa que no la garantiza.

## Profundización

CSV no equivale a separar por comas: campos entre comillas pueden contener delimitadores y saltos de línea. Para formatos reales usá un parser adecuado y límites de tamaño, columnas y cantidad de registros.
