## Concepto

Ordenar no es solamente obtener números de menor a mayor. Elegí criterio, tratamiento de empates y si podés modificar la entrada. Un algoritmo estable conserva el orden previo entre elementos que comparan como iguales: sirve, por ejemplo, para mantener llegada entre pedidos del mismo monto.

Bubble sort compara vecinos e intercambia los que están invertidos. Es didáctico, pero cuesta O(n²) en promedio y peor caso. Con detección de ausencia de intercambios, una entrada ya ordenada termina en O(n). Requiere O(1) espacio auxiliar y es estable si no intercambia iguales.

Quicksort particiona alrededor de un pivote y ordena las partes. Su promedio típico es O(n log n), pero puede llegar a O(n²) con particiones desequilibradas. La pila de recursión también ocupa espacio. Una implementación habitual no es estable; elegir mejor el pivote reduce riesgos, no convierte automáticamente su peor caso en O(n log n).

## Ejemplo

Java 21, fragmento para colocar dentro de una clase:

```java
static void burbuja(int[] valores) {
    for (int limite = valores.length - 1; limite > 0; limite--) {
        boolean cambio = false;
        for (int j = 0; j < limite; j++) {
            if (valores[j] > valores[j + 1]) {
                int temporal = valores[j];
                valores[j] = valores[j + 1];
                valores[j + 1] = temporal;
                cambio = true;
            }
        }
        if (!cambio) return;
    }
}

// Partición de Lomuto; el último elemento es el pivote.
static void quicksort(int[] a, int inicio, int fin) {
    if (inicio >= fin) return;
    int pivote = a[fin], frontera = inicio;
    for (int j = inicio; j < fin; j++) {
        if (a[j] <= pivote) {
            int temporal = a[frontera];
            a[frontera++] = a[j];
            a[j] = temporal;
        }
    }
    a[fin] = a[frontera];
    a[frontera] = pivote;
    quicksort(a, inicio, frontera - 1);
    quicksort(a, frontera + 1, fin);
}
```

Invocá `quicksort(array, 0, array.length - 1)`. Este pivote simple exhibe el peor caso en entradas ya ordenadas y no es la elección recomendada para producción.

Para código de aplicación preferí `Arrays.sort(array)` o `lista.sort(comparator)`. El JDK puede usar estrategias distintas para primitivos y objetos: no memorices «Java siempre usa quicksort». Los contratos de ordenamiento de objetos garantizan estabilidad donde está documentada.

## En entrevista

**Pregunta:** ¿Qué criterios usarías para elegir un algoritmo de ordenamiento?

**Breve:** comparo complejidad, estabilidad y memoria; para producción suelo usar el ordenamiento del JDK con un comparador correcto.

**Ampliada:** puedo explicar bubble para demostrar intercambios y quicksort para partición y recursión. Validaría entradas ordenadas, invertidas y repetidas; usaría mediciones representativas si el rendimiento fuera relevante.
## Error frecuente

Suponer que ordenar una copia no cambia sus objetos: se copia la estructura, pero las referencias siguen apuntando a los mismos elementos.

## Práctica

Seguí una pasada de bubble sobre `[5,1,4,2]`. Luego particioná esos valores alrededor del pivote 4.

### Pista

Bubble mueve el máximo al final; una partición agrupa a cada lado del pivote.

### Solución

La pasada deja `[1,4,2,5]`. Una partición válida alrededor de 4 es `[1,2,4,5]`, aunque el orden interno de cada lado depende del método. Quicksort todavía debe resolver recursivamente las regiones; el ejemplo pequeño puede ocultar ese trabajo.

## Profundización

Para obtener solo los k pedidos prioritarios puede ser mejor mantener un heap de tamaño k que ordenar todo. Formular la necesidad exacta evita optimizar un trabajo que no era necesario.
