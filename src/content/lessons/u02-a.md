## Concepto

Java tiene ocho tipos primitivos: `byte`, `short`, `int`, `long`, `float`, `double`, `char` y `boolean`. Una variable de referencia apunta a un objeto o contiene `null`. Un array también es un objeto: fija su longitud al crearse, aunque sus posiciones puedan cambiar. Las variables locales deben inicializarse antes de usarse; los campos reciben valores iniciales por defecto.

Usá `if` para condiciones, `switch` para alternativas y bucles para repetir. Elegí nombres que expliquen el dominio: `unidadesDisponibles` comunica más que `x`. Java pasa argumentos por valor: al pasar un objeto copia el valor de la referencia, no el objeto. El método puede cambiar ese objeto mutable, pero reasignar su parámetro no cambia la variable del llamador.

`String` es inmutable. `==` compara referencias; `equals` compara contenido según el contrato de la clase. Los wrappers, como `Integer`, permiten representar primitivos como objetos y usarlos en genéricos. Autoboxing convierte de primitivo a wrapper; unboxing hace lo inverso. Desempaquetar `null` produce `NullPointerException`.

## Ejemplo

Java 21 ejecutable; guardalo como `Tipos.java` y ejecutá `java Tipos.java`:

```java
import java.util.Objects;
class Tipos {
    public static void main(String[] args) {
        String sku = new String("LIBRO");
        System.out.println("LIBRO".equals(sku)); // true
        Integer stockInformado = null;
        int stock = Objects.requireNonNullElse(stockInformado, 0);
        for (int unidad = 0; unidad < stock; unidad++) {
            System.out.println("Preparar unidad " + unidad);
        }
        System.out.println(5 / 2);   // 2: división entera
        System.out.println(5 / 2.0); // 2.5
    }
}
```

Elegir cero ante ausencia es una regla del ejemplo, no una solución universal: puede ser necesario distinguir «sin stock» de «stock desconocido».

## En entrevista

**Pregunta:** ¿Cuándo usarías `==` y cuándo `equals` al comparar valores en Java?

**Breve:** primitivos almacenan valores; referencias permiten acceder a objetos. Comparo contenido de Strings con `equals` y controlo `null` al usar wrappers.

**Ampliada:** dos wrappers pueden compartir instancia por cachés internas, por lo que `==` parece funcionar para ciertos números y falla para otros. Para dinero usaría `BigDecimal` con escala y redondeo definidos, no `double` como aproximación binaria.
## Error frecuente

Creer que `final` o `String` hacen inmutable cualquier objeto al que se refieran. Inmutabilidad es una propiedad del diseño del objeto.

## Práctica

Un precio es 199 centavos y comprás tres unidades. Calculá total y mostralo como unidades monetarias sin perder centavos.

### Pista

Conservá la unidad mínima durante el cálculo.

### Solución

El total es `199L * 3`, es decir 597 centavos. Para mostrarlo, `BigDecimal.valueOf(597, 2)` representa 5.97 exactamente. Acordá moneda y redondeo si aparecen fracciones de centavo.

## Profundización

Los enteros pueden desbordar sin lanzar excepción; `Math.addExact` y `multiplyExact` lo detectan. `char` representa una unidad UTF-16, no siempre un carácter visible completo.
